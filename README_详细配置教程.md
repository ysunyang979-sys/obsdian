## 1. 是否需要提供仓库地址及准备工作

### ❓ 需要提供仓库地址吗？
**是的，必须有一个 GitHub 仓库地址作为中转站。**

- **如果你想让我帮你直接配置并推送**：直接把你在 GitHub 上建好的仓库地址（如 `https://github.com/ysunyang979-sys/xxx.git` 或 `git@github.com:...`）发给我，我可以直接帮你写入配置并完成首次 Git 初始化与推送。
- **如果你想自己填入**：打开 `BAT脚本/00_配置.bat`，将 `REPO_URL` 修改为你自己的仓库地址即可。

### 🚀 如何在 GitHub 创建私有仓库（1分钟）：
1. 登录 [GitHub](https://github.com/)，点击右上角 **`+` → New repository**。
2. 填写仓库名（如 `obsidian-study` 或 `obsidian-notes`）。
3. 选择 **Private（私有）**（⚠️ 务必选私有，保护笔记隐私）。
4. **【极其重要】不要勾选** `Add a README file`、`Add .gitignore`、`Choose a license`（保持为一个完全空白的仓库）。
5. 点击 **Create repository**，复制页面的 HTTPS 地址（如 `https://github.com/ysunyang979-sys/obsidian-study.git`）。

## 3. BAT 脚本清单与功能说明

所有脚本均已存放在 `BAT脚本/` 目录下，并经过增强优化：

| 脚本名称 | 适用电脑 | 功能与运行场景 |
| :--- | :--- | :--- |
| **`00_配置.bat`** | 通用 | 集中配置 GitHub 仓库地址与本地笔记路径（A 电脑已预设为 `F:\Tools\obsidian\cangku\first`） |
| **`A_首次上传.bat`** | A 电脑 | 首次使用时双击：自动部署 .gitignore、初始化 Git、关联远程仓库并全量推送 |
| **`一键双向同步.bat`**<br>*(或 `A_D_立即上传.bat`)* | A / D 电脑 | **日常高频使用**：一键保存本地修改 → 自动从 GitHub 拉取更新 → 自动推送至远端 |
| **`D_首次下载并打开.bat`** | D 电脑 | 新电脑首次使用时双击：自动从 GitHub 克隆笔记到本地并唤起 Obsidian |
| **`D_一键打开最新版.bat`** | D 电脑 | 在第二台电脑学习前双击：先自动拉取 GitHub 最新笔记，再启动 Obsidian |
| **`检查大文件.bat`** | 通用 | 自动扫描库中 >50MB 的大文件（防 GitHub 限制）及未解决的 Git 冲突标记 |

## 4. A 电脑（当前电脑）首次上传操作

1. 确认在 GitHub 创建好了 **Private 空仓库**。
2. 打开 `BAT脚本/00_配置.bat`，确认 `REPO_URL` 为你的真实 GitHub 仓库地址。
3. 双击运行 `BAT脚本/A_首次上传.bat`。
4. 若弹出 GitHub 登录验证窗口，完成浏览器授权登录即可。
5. 提示 `【成功】首次上传完成` 后，刷新 GitHub 网页即可看到你的全部笔记。

## 5. D 电脑（第二台电脑）首次下载与日常使用

### 第 1 步：D 电脑准备
1. 安装 [Git for Windows](https://git-scm.com/) 和 [Obsidian](https://obsidian.md/)。
2. 将 `BAT脚本` 文件夹复制到 D 电脑（例如放在桌面或 D 盘）。

### 第 2 步：修改 D 电脑配置
打开 D 电脑上的 `00_配置.bat`：
- `REPO_URL`：保持与 A 电脑相同的 GitHub 仓库地址。
- `VAULT_PATH`：修改为 D 电脑上希望存放笔记的目录（例如 `D:\Obsidian\MyNotes`）。

### 第 3 步：首次克隆
- 双击运行 `D_首次下载并打开.bat`，会自动拉取全部笔记并打开 Obsidian。

### 第 4 步：D 电脑日常使用
- 每次学习前：双击 `D_一键打开最新版.bat`（自动拉取 A 电脑的最新修改后打开软件）。
- 每次学习结束：双击 `一键双向同步.bat`（自动提交并上传至 GitHub）。

## 6. 推荐插件与最佳配置

已在你的笔记库中检测到已启用插件（`Dataview`、`Spaced Repetition`、`Excalidraw`），以下为核心推荐设置：

### 1. Spaced Repetition（间隔重复与闪卡自测）
- **行内制卡**：在任何笔记中用 `问题::答案` 即可快速制卡。
- **标签制卡**：在笔记中加入 `#flashcards` 或 `#flashcards/言语理解`。
- **快捷复习**：按 `Ctrl + P` 运行 `Spaced Repetition: Review Flashcards from all notes`。

### 2. Dataview（主页聚合看板）
- 打开 `00-学习主页.md` 即可自动实时汇总未掌握错题、最近修改笔记等。
- 确保在设置中开启 `Enable JavaScript Queries`。

### 3. Templater / 核心模板
- 在设置中将 **模板文件夹位置** 指定为 `Templates`。
- 录入错题或词语时直接插入对应模板。

### 4. Image Converter（强烈推荐安装）
- **作用**：将粘贴到笔记中的截图自动转换为 WebP 格式（体积缩小 70%~90%），防止 GitHub 仓库膨胀变慢。
- **推荐设置**：
  - Convert pasted images: `ON`
  - Output format: `WEBP`
  - Quality: `80`

## 7. 防冲突与日常学习最佳工作流

### 💡 黄金法则：**“学前拉取，学后推送，不同时开”**

```text
【在 A 电脑学习】：
1. 打开 Obsidian（已有最新笔记）
2. 刷题、做笔记、用 Templates 记错题
3. 学习结束：双击「一键双向同步.bat」推送到 GitHub

       ↓ （通过 GitHub 云端同步）

【在 D 电脑学习】：
1. 双击「D_一键打开最新版.bat」（自动拉取 A 电脑成果并打开 Obsidian）
2. 继续学习、自测复习
3. 学习结束：双击「一键双向同步.bat」推送到 GitHub

       ↓ （通过 GitHub 云端同步）

【回到 A 电脑】：
1. 双击「一键双向同步.bat」拉取 D 电脑的新增笔记
2. 愉快的继续学习！
```

### 遇到冲突怎么办？
如果不小心在两台电脑离线修改了同一篇笔记：
1. 双击 `检查大文件.bat` 会自动扫描带有冲突标记的文件。
2. 打开冲突的 Markdown 文件，搜索 `<<<<<<<`。
3. 手动保留想要的内容并删除 `<<<<<<<`、`=======`、`>>>>>>>` 分割线。
4. 重新双击 `一键双向同步.bat` 即可恢复正常。
